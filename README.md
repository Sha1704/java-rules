# Project Overview

This project provides a collection of programming rules and best practices for Java developers. It serves as a guideline to promote quality and maintainability within Java applications.

## Prerequisites

Before you begin, ensure you have met the following requirements:

- Java 8 or higher installed on your system.
- Familiarity with IDEs (e.g., VScode, IntelliJ IDEA, Eclipse).

## Installation

To install this project, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/Sha1704/java-rules.git
   ```
2. Navigate to the project directory:
   ```bash
   cd java-rules
   ```
3. Open the project in your preferred IDE.
4. Run the following commands in your terminal:
   ```bash
   javac -cp ".;ojdbc17.jar" app/Main.java
   java  -cp ".;ojdbc17.jar" app.Main
   ```
5. use "rm app/*.class" to clean up excess .class file
6. you have to be connected to the ISU's wifi to suscessfully run the program
7. When prompted for an ID, the ID is 1
